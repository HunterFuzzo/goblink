# Blink — Point at the question. Get the answer.

> AI answers for any question on screen. Official website for Blink macOS.

## Live Website
Deployable directly on Vercel at [blink.vercel.app](https://blink.vercel.app).

## Features
- **Modern Apple Dark Minimalist Design**: Faithful Swiss Dark Tech precision styling with pure dark background, subtle concentric cards, and typography.
- **Bilingual Support (EN / FR)**: Instant toggle between English and French without page reloads, persisted in `localStorage`.
- **Left Dropdown Navigation**: Minimalist round button with Login modal and direct Yellow Subscribe action.
- **Pricing Cards**:
  - **Free**: 0 € (3 question analysis credits, Caps Lock LED & iPhone Vibration, High-precision OCR).
  - **Pro**: 2.99 € / month (500 research, All indication modes, Stealth mode & unlimited access). Connected to live Stripe Checkout.
  - **Max**: 4.99 € / month (1,500 research, VIP Priority Support, Early access).
- **FAQ Accordion**: Clean interactive accordion with answers to key exam, stealth, and Mac compatibility questions (zero mention of Windows).
- **Vercel Ready**: Static optimization with custom caching and security headers via `vercel.json`.

## Deployment to Vercel
1. Go to [Vercel](https://vercel.com).
2. Click **Add New Project** and import `blink-org/blink-web`.
3. Set domain to `blink.vercel.app`.
4. Click **Deploy**.
